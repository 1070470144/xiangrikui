# 植物扩展阶段 1 / 2 功能记录

默认五个植物槽，光脉芽与修复是基础动作，不占槽。每白天可携带 1–5 个不同物种；空槽允许保留，不允许空携带或重复物种。夜晚不能调整或部署。调整不移除已种植物，重开恢复默认五种。

目录包含原五种及十种新植物，滚动目录与五个可见槽框分离，选第六种由 UI 拒绝，游戏接口同样校验上限。名字、种子费用、功能描述由数据与 `plant_roster.gd` 统一映射。

| 新植物 | 真实功能 |
| --- | --- |
| 雷链花 | 170 距离选敌，85 距离雷链跳转最多三次，每跳伤害递减 |
| 风铃草 | 伤害加击退 35，首领免推 |
| 日泉花 | 夜晚每八秒产生两光，低光减为一光，休眠停止 |
| 焰蕊花 | 直伤加每秒四伤害、持续三秒灼烧 |
| 眠孢花 | 0.8 秒眩晕，首领缩短至四分之一 |
| 穿叶竹 | 230 长度、18 半宽直线，贯穿最多四敌 |
| 爆果花 | 目标周围 65 范围，最多八敌，走范围减伤规则 |
| 石盾花 | 240 生命，承伤降低 40% |
| 净露兰 | 周围植物清腐蚀并治疗三生命 |
| 鼓舞葵 | 周围植物攻击间隔乘 0.85，离开范围后限时失效，多个来源不叠乘 |

植物 Kind 与部署 Selection 不同（光脉芽占 Selection 2），因此供光负载与移植成本改为使用物种数据，避免把守灯花当光脉芽计价。友方归化敌人不被新范围、链式或原荆棘攻击选择。

实际 Godot 检查：`tests/test_plant_slots_expansion.gd` 46 项通过，覆盖五槽默认、六槽拒绝、重复拒绝、日夜限制、UI 上限、重开、十种实际供光落地及单次种子扣费、十种战斗行为与状态到期。`tests/test_day_night_flow_independent.gd` 原 117 项通过，首次四张、逐夜两张战术牌流程不变。
