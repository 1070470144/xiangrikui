# 卡组详情与拖拽 · 2026-09-30

点击卡库卡牌或卡组条目打开完整详情；拖拽开始时取消点击，避免同时打开弹层。详情包含插画、光能使用消耗、品质、可用时段、目标、携带上限、编入数量、种子解锁费用、自然语言效果与数值。全部 24 张卡的描述按当前 `card_effect_resolver.gd` 和临时战斗对象实现核对，包含首领控制折减、复活及幻影条件。可通过关闭、点击遮罩或 Escape 返回。

卡库卡牌可拖入右侧卡组，卡组行可拖回左侧卡库，一次移除一张。使用 Godot 原生拖放和跟随鼠标的插画预览；拖放目的区域以金边提示。卡面、行文本及其按钮都支持转发拖放。空卡组提供落点提示。未解锁、满组、复制上限及稀有/传奇配额由现有 Model 校验；无效落点与取消不修改草稿。只接受同一界面实例产生的卡牌载荷，提交延迟到回调结束，避免释放拖拽源。

验证入口 `tests/test_deck_builder_runner.gd`：无头测试验证详情和落点规则；图形模式额外通过 Viewport 注入鼠标按下、移动和松开，执行真实原生点击/双向拖放，并检查拖拽不会打开详情、重复卡限制、无效落点保持草稿。截图为 `tmp/deck-builder-detail-final.png`。
