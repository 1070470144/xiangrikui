# 第四夜复合天气交付记录

第四夜继续使用 `thunderstorm` 规则，启用第三夜的酸雨透明动画和原有每秒生命损失，同时播放雷雨云层和独立雷光。酸雨计时与雷雨地形计时分离，避免每秒酸雨重置阻止四秒地形事件。未改关卡顺序、基础属性或卡牌永久配置。

天气有效条件：夜晚、未封印、战斗未结束。运行时倍率：第三/四夜敌方攻击 ×1.10；第四夜敌方移动 ×1.10、己方治疗和节点修复 ×0.85；第五夜植物攻击间隔 ×1.15。母花治疗、植物治疗、节点修复、普通攻击、冲撞与敌方特殊攻击均使用实时倍率。转白天、封印和终局后恢复，不重复叠加。

第五夜雾前沿沿用现有雾 Shader 和灯光 reveal mask，从第七圈（1400 世界单位）在 45 秒内推进到第二圈（400 世界单位）；每圈 200 单位。封印暂停蔓延并隐藏，恢复后继续；新雾夜和重开清零。局部灯光驱雾机制保留。
