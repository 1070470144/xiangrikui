# 战斗场景可读性优化设计

日期：2026-09-30  
范围：战场内威胁反馈、母花危险反馈、战斗 HUD 降噪  
目标：玩家不依赖右侧仪表，也能从战场判断敌人来向、威胁强度和母花危险状态

## 1. 已确认方向

采用“低遮挡 HUD + 世界危险信号”。保留现有昼夜双态 HUD、底部卡牌操作和战斗规则；不重做正式界面，不生产新美术，不调整数值平衡。世界空间反馈承担方向与危险的首要表达，HUD 只保留精确状态和次级确认。

核心验证循环：敌群即将生成 → 战场边缘给出方向与强度 → 敌群进入战场 → 母花近域和受击状态可见 → 玩家部署或使用战斗牌应对 → 提示按生命周期退场。

## 3. 现状诊断

现有实机截图显示：顶部通知横条持续切断中央视野；右侧战术仪表承担了主要来向信息；夜间底部手牌占据较大面积。母花本体虽处于中央，却缺少随危险状态变化的世界反馈。玩家必须在战场、顶部状态和右侧雷达之间频繁切换视线。

本次保留底部操作区，以免把可读性优化扩展成另一次 HUD 重做。主要空间从顶部中央和战场边缘回收。

## 4. 组件设计

### 4.1 世界边缘威胁提示

新增单一职责的世界节点，读取现有八方向威胁快照，不自行计算或修改战斗规则。

- 与现有八个入口一一映射，位置来自 `BattlefieldSpec.get_spawn_positions()` 或相同权威数据源。
- 普通预警由边缘方向弧、朝中心的短箭头和一次向内脉冲组成。
- 强度映射到提示尺寸、透明度和脉冲频率；颜色只区分普通、严重、首领三档，避免连续彩虹编码。
- 首领方向增加独立外轮廓和较慢的双脉冲，不依赖文字“BOSS”。
- 提示位于世界空间，不接收鼠标事件，不阻挡部署、选择或镜头控制。
- 威胁降为零后平滑退场，不保留永久标记。

### 4.2 母花危险环

母花周围增加非交互式状态环，不重复 HUD 数字。

- 安全：低透明度、静止。
- 近域受威胁：按附近敌人或已有危险状态增强亮度，轻微呼吸。
- 受击：短促外扩闪烁，持续时间独立，不因连续伤害永久常亮。
- 低生命：使用稳定但克制的危险色轮廓；不使用高速闪屏。
- 状态环跟随母花世界位置和镜头缩放，不作为 CanvasLayer HUD。

### 4.3 短暂地面预警

只为已有明确影响范围的攻击或事件显示地面形状；不新增攻击机制。

- 圆形范围使用轮廓加轻透明填充，方向攻击使用扇形或走廊轮廓。
- 预警在效果前出现、触发时收束、结束后销毁。
- 图形节点不参与碰撞和输入；实际命中仍由原规则决定。
- 若当前代码没有可复用的攻击预告数据，本轮仅实现生成方向与母花危险环，不为视觉效果伪造战斗数据。

### 4.4 HUD 降噪

- `NotificationBanner` 保持事件触发式显示，但压缩高度和最大宽度，并缩短非关键消息时长。
- 普通通知放在阶段栏下方且不横贯中央；危险通知可以提升颜色和时长，但仍自动消失。
- `TacticalInstrumentFrame` 在白昼或零威胁时降低透明度；出现有效威胁、首领或光脉异常时恢复完整强调。
- 仪表继续显示精确信息，作为世界提示的补充，不再是识别来向的唯一渠道。
- 底部卡牌和主操作按钮保持尺寸、位置、信号与快捷键契约。

## 5. 数据流与边界

`Game` 继续作为战斗状态权威来源。现有威胁数组、首领方向、母花生命和受击信号通过只读快照或信号传给表现节点：

`Game 状态 → 世界反馈控制器 → 八方向提示 / 母花危险环`  
`Game 状态 → HUD → 精确数值 / 战术仪表 / 临时通知`

表现节点不得生成敌人、修改伤害、改变波次、扣除资源或决定胜负。HUD 和世界反馈可同时消费同一快照，但不得互相读取内部节点状态。

## 6. 错误与降级处理

- 缺少某个入口节点时跳过对应提示并报告明确警告，不阻断战斗。
- 威胁快照长度不是八时，按可用数据安全裁剪，缺失方向视为零。
- 世界反馈控制器缺失时，现有 HUD 和战斗仍可运行。
- 不增加外部素材依赖；所有原型反馈使用 Godot 绘制节点、基础形状和现有颜色令牌。

## 7. 测试与实机验收

先添加会失败的行为测试，再实现功能。

自动测试覆盖：

- 八个入口与八方向索引稳定映射；
- 零、普通、高危、首领威胁生成不同且确定的表现状态；
- 提示生命周期能出现、更新并退场；
- 所有世界反馈节点不接收鼠标输入且无碰撞职责；
- 母花安全、近域、受击、低生命状态转换正确；
- 通知自动隐藏，零威胁时战术仪表降噪；
- 既有战斗 HUD、战场规格和游戏流程测试不回归。

实机验收覆盖白昼、普通夜战、多方向来袭、首领来袭、母花受击和低生命六种状态。最低分辨率 1152×648 下验证：

- 不看右侧仪表也能在一秒内判断主要来向；
- 母花始终可定位，受威胁方向明确；
- 世界提示不遮挡部署目标、不阻止点击；
- 顶部通知不再长期切断中央战场；
- 成功、失败和重新开始流程保持可用；
- Godot 调试器无新增错误或持续警告。

## 8. 非目标

- 不修改卡牌、资源、敌人、波次或难度数值；
- 不重做底部卡牌托盘、母花强化选择或结算界面；
- 不生成正式 UI、美术、音频或动画资产；
- 不把调试覆盖层变成正式 HUD；
- 不复制参考游戏的受保护表达。

## 9. 完成标准

完成必须同时包含可运行的战场反馈、精确的可复现测试和实际 Godot 运行证据。仅有设计稿、静态效果、截图或未运行的测试文件均不算完成。
