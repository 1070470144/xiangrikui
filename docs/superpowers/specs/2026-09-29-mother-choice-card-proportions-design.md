# 母花强化卡牌防拉伸优化设计

## 目标

修复母花三选一卡牌复用横向按钮纹理后被纵向拉伸的问题，在不生成新图片、不覆盖现有资源的前提下，建立稳定的竖版卡牌比例和清晰的信息层级。

## 成熟游戏参考

### Hades — Boon Selection

- 可核验来源：[Game UI Database — Choose Boon/Upgrade](https://www.gameuidatabase.com/)
- 借鉴点：选择项拥有独立卡片轮廓；名称、类型和效果分层显示；卡片视觉不会因文字量改变而变形。
- 项目适配：保留全屏暗色遮罩和三等分结构，将母花方向名称与方向说明分层放入稳定尺寸卡片。
- 不采用：不复制角色肖像、神祇品牌元素或原作装饰资产。

### Brotato — Level Up Upgrades

- 可核验来源：[Brotato Wiki — Upgrades](https://brotato.wiki.spellsandguns.com/Upgrades)
- 借鉴点：候选项尺寸一致、间距固定，升级名称和效果可以快速扫读。
- 项目适配：三张卡固定宽高，统一内部留白和文字对齐，悬停只改变亮度与位置反馈。
- 不采用：不使用其扁平白底、彩色稀有度或四选一结构。

## 视觉结构

- 使用已有 `res://assets/ui/generated/UI_Card.png` 作为专用卡牌底图。
- 通过 `AtlasTexture` 裁掉图片外围透明区域，仅保留实际卡框区域，再转换为 `StyleBoxTexture` 九宫格。
- 卡牌使用约 `240 × 300` 的竖版尺寸，三张等宽、等高、等间距水平排列。
- 卡牌标题位于上半部，方向类型与三个分支位于下半部；文字由 Godot 字体绘制，不烘焙进图片。
- 普通、悬停、按下状态共用同一稳定卡框比例，通过颜色调制、描边亮度或轻微上移提供反馈，禁止缩放纹理。
- 中央选择面板适度收窄，并减少无信息空白，使视觉焦点集中在三张卡牌。

## 实现边界

- 为母花选择创建专用卡牌样式函数，不再调用通用 `_button()` 的横向 `UI_Button_*` 样式。
- 保持现有 `mother_card_requested` 信号、选择数据和全屏遮罩逻辑不变。
- 更新 `battle_hud.json`，记录卡牌底图、裁剪区域、九宫格边距、运行时节点绑定和参考资料。
- 本轮所有资源复用现有文件，`generation.enabled` 保持为 `false`，不调用 `mm-api`。

## 验收标准

1. 三张卡牌保持统一竖版比例，边框、花饰和底纹无明显纵向拉伸。
2. 1152×648、1280×720 和 1920×1080 下三张卡均完整位于选择面板内。
3. 卡牌文字不溢出，标题与说明层级清楚。
4. hover/pressed 有反馈，但卡牌纹理比例不变化。
5. 选择行为、全屏遮罩、空候选隐藏和现有 HUD 测试继续通过。
