# 主菜单右侧“温室园丁档案”重设计规格

> 日期：2026-09-29  
> 状态：待用户复核  
> 目标：使右侧主菜单与废弃维多利亚温室背景形成同一套视觉语言。

## 1. 范围与功能定位

本次仅调整主菜单右侧区域的视觉表现，不改变页面位置、按钮顺序、存档逻辑、键盘导航、点击区域或页面跳转。

右侧区域定位为园丁留在温室中的旧档案页，而不是东方卷轴或独立牌匾。它负责承载账号状态、当前守夜进度和五个主菜单操作，同时让左侧向日葵继续成为第一视觉焦点。

## 2. 原项目风格证据

- 主背景是冷蓝夜色中的废弃维多利亚温室，包含破损玻璃、铁制骨架、旧花盆、枯萎植被和局部暖金太阳光。
- 项目既有 UI 语言是“旧园艺记录册 + 发光仪器”，主色为墨绿、冷蓝黑、旧黄铜和暖金。
- 向日葵是画面最亮、最暖的主体；右侧 UI 应保持低亮度、低饱和度和较低纹样密度。
- 当前古籍卷轴中的中式边纹、牌匾式按钮和大面积亮金与背景建筑语言冲突，必须移除。

本次是既有区域的视觉重做，不新增或优化功能布局，因此不引入外部商业游戏布局调研。《黑神话》只保留其留白、信息层级和克制状态反馈原则，不复制其美术资产或中式视觉符号。

## 3. 布局与信息层级

- 保留右侧约 346 × 506 的现有菜单范围。
- 账号入口仍位于右上角，但改为小型黄铜园丁铭牌，与档案面板共享材质。
- 面板标题恢复为“园丁记录”，下方显示小号档案编号或温室状态文字。
- “继续守夜”仍是唯一主操作，尺寸和焦点优先级不变。
- 存档摘要紧随主操作，使用低对比暖灰金。
- 卡组配置、七夜记录、温室图鉴和设置采用档案目录行，不使用封闭厚重牌匾。
- 退出游戏保持最低视觉权重。

## 4. 视觉设计

### 4.1 档案面板

- 深墨绿色旧档案纸或涂漆金属底，允许极轻纸纤维和氧化斑驳。
- 边缘结合细黄铜压条与局部破损玻璃，不出现卷轴、云纹、印章或东方牌匾结构。
- 面板外轮廓应融入背景阴影，不能像一张高亮海报贴在画面上。
- 装饰集中在边缘，中央交互区域保持低细节。

### 4.2 账号铭牌

- 使用旧黄铜框、暗绿珐琅或磨损金属底。
- 仅显示园丁符号、玩家名称与“本地存档”。
- 不使用朱砂印章或中式题签。

### 4.3 按钮状态

主按钮和目录按钮均生成 normal、hover、pressed、disabled 四态，文字仍由 Godot 绘制。

- normal：低亮度墨绿/黑玻璃底，细黄铜边。
- hover：边缘出现一次柔和向日葵暖光，不能整体变亮。
- pressed：底色略暗，黄铜边框收紧。
- disabled：降低饱和度和亮度，但文字仍可读。
- 所有素材中央至少 75% 区域保持无图案、无高光、无文字，避免压住标签。

### 4.4 色彩与密度

- 冷蓝黑：取自温室夜景阴影。
- 墨绿：取自背景叶片与旧金属涂层。
- 旧黄铜：取自背景暖色边缘光，不使用高饱和亮金。
- 暖金只用于焦点、悬停和进度强调。
- 右侧 UI 的平均亮度必须低于左侧向日葵主体。

## 5. MM 资源拆分

Manifest 将更新并生成以下资源：

1. 温室园丁档案面板一张。
2. 黄铜园丁账号铭牌一张。
3. 植物学档案分隔线一张。
4. 小型园丁/温室档案徽记一张。
5. 主按钮四态四张。
6. 目录按钮四态四张。

共十二张。所有资源使用新文件名，避免覆盖现有卷册素材；旧素材保留但解除运行时绑定。

## 6. 运行时与失败回退

- Godot 继续负责文字、焦点框、动态存档内容和交互。
- 新资源缺失或验证失败时回退到可读的原生 StyleBox，不让菜单失效。
- `start_requested`、账号切换、子页面入口及 Esc 返回契约保持不变。
- 不修改本地存档格式。

## 7. 验收标准

- 1152 × 648 实际 Godot 截图中，面板与温室背景使用一致的色温、材质和装饰语言。
- 右侧面板不再出现卷轴、朱砂印章、中式牌匾或高密度亮金花纹。
- 向日葵仍是最亮、最先被注意的区域。
- 所有按钮四态来自独立素材，文字安全区无装饰遮挡。
- 主菜单契约、布局测试和 MM Manifest 验证通过。
- 最终截图逐项对照本规格，不存在未处理差异。
