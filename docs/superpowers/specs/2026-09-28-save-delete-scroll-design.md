# 存档删除与滑动列表设计

## 目标

园丁档案页支持安全删除本地存档，并在存档数量较多时通过固定高度的纵向滑动列表浏览，避免页面底部被裁剪。

## 交互规则

- 每个存档条目显示名称、当前状态、切换按钮与删除按钮。
- 点击删除后显示确认对话框；确认后才修改本地数据。
- 最后一个存档不可删除，对应删除按钮禁用。
- 删除当前存档后，自动切换到删除位置之后的存档；若其不存在，则切换到前一个存档。
- 删除非当前存档时，当前存档保持不变。
- 创建存档输入区位于滚动列表之外，始终可见。

## UI 结构

账号页沿用现有模态面板。账号条目放入 `ScrollContainer` 内的 `VBoxContainer`，滚动区域占据可伸缩的中部空间；统计、创建区和返回按钮不随列表滚动。

## 持久化与错误处理

删除成功后同时保存账号集合和当前 profile。不存在的账号或最后一个账号删除请求返回 `false`，不修改文件或当前账号。
