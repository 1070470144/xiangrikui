# mm-tools 开发期间禁止 Git 操作

## 目标

为 `mm-tools` 增加明确的开发期安全边界：技能生效期间不得执行任何 Git 或托管平台仓库操作，除非用户随后明确解除该限制。

## 设计

- 在 `aiskill/mm-tools/SKILL.md` 的固定流程之前增加独立的“开发期间禁止 Git 操作”章节，确保约束在执行步骤前可见。
- 禁止所有 Git 命令，不区分只读或写入，包括状态检查、差异查看、暂存、提交、分支、工作树、回滚、合并、推送和拉取。
- 同时禁止通过 GitHub CLI、托管平台 API 或其他工具间接修改仓库、分支、提交和拉取请求。
- 允许使用普通文件与目录工具了解项目状态、编辑文件和运行测试。
- 只有用户在后续消息中明确授权 Git 操作时才可解除限制；不得把一般性的“继续”“完成”解释为授权。

## 验证

- 检查技能正文包含独立约束章节和明确的解除条件。
- 运行技能结构验证器，确认 `SKILL.md` 仍具有有效 frontmatter。
- 全程不执行任何 Git 命令。
