# 主菜单控件视觉重设计

## 目标

重新设计《最后的向日葵》主菜单右侧控件，解决按钮缺少设计感、素材被压缩以及顶部存档入口过于简单的问题。新素材必须与夜间温室大背景共享同一套暗绿玻璃、氧化黄铜和克制植物纹样语言。

## 视觉方向

采用“克制温室风”：装饰集中在边缘与四角，中央文字区域保持安静。材质包括暗绿色旧玻璃、细黄铜压边、轻微磨损和少量藤蔓刻纹。禁止厚重雕花、强烈外发光、文字、伪文字、场景插画和多层按钮叠加。

## 素材规格

### 主按钮

- 运行时显示尺寸：290 × 64。
- 生成母版比例与运行时一致，不允许通过非等比缩放改变外观。
- 四角和左右两端仅保留小型藤蔓角饰；中央至少 72% 为文字安全区。
- normal、hover、pressed、disabled 四态使用完全一致的轮廓，只改变亮度、饱和度和按压深度。

### 次级按钮

- 运行时显示尺寸：290 × 52。
- 与主按钮同宽，边框更细、装饰更轻。
- 中央至少 78% 为文字安全区。
- 四态轮廓和装饰位置必须一致。

### 右侧菜单面板

- 运行时显示尺寸：346 × 506。
- 半透明暗色玻璃面板，四角使用细黄铜结构和淡藤蔓纹理。
- 中央区域保持低对比，不绘制温室场景或第二层背景。
- 面板只承担分组和可读性，不与主背景争夺视觉焦点。

### 顶部存档牌

- 运行时显示尺寸：278 × 58。
- 左侧设置小型种子/嫩芽徽记槽，右侧为平整的双行文字区。
- 使用与菜单面板相同的玻璃和黄铜材质，悬停态只增强边缘暖光。

## 生成与处理

- 使用 `sprite-gen` 和项目已确认的 `gpt-image-2` OpenAI 兼容端点生成母版。
- 每类素材独立生成，按目标比例裁切；不得把正方形素材直接压缩成横向控件。
- 纯色背景通过 `sprite-gen cutout` 标准流程移除。
- 按钮交互态从同一确认母版派生，保证像素轮廓一致。
- 原始图、提示词和生成报告保存在 `art_source/`；运行时 PNG 保存在 `assets/ui/generated/`。

## Godot 接入

- 主按钮和次级按钮使用 `StyleBoxTexture`，纹理尺寸比例与控件比例一致。
- 仅在边缘尺寸稳定且不会挤压中央区域时使用九宫格；否则采用整图等比缩放。
- `MenuJournal`、`AccountEntry` 和按钮绑定统一由 `art_source/manifests/main_menu.json` 管理。
- 保留现有节点名称、信号、键盘焦点与菜单功能。

## 验证

- 检查所有运行时图片的尺寸、RGBA 透明通道和状态轮廓一致性。
- 美术契约测试验证按钮显示比例与素材比例一致。
- 主菜单截图确认按钮无压缩、面板不形成第二张背景、存档牌与菜单面板材质统一。
- 运行既有主菜单交互测试，确认开始、卡组、记录、图鉴、设置和账号入口仍可使用。
