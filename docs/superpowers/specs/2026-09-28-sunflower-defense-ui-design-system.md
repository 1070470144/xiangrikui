# 《最后的向日葵》整体 UI 设计规范

> 日期：2026-09-28  
> 状态：设计确认稿  
> 适用引擎：Godot 4.7  
> 基准画面：1152×648，16:9  
> 设计方向：沉浸叙事型 × 克制高级感  
> 视觉主题：旧园艺记录册 + 发光温室仪器

## 1. 目标

UI 必须让玩家感觉自己正在使用一套属于末日温室守护者的工具：主菜单是园丁记录册，图鉴是植物标本档案，卡组是种子卡匣，战斗 HUD 是黄铜观测仪器，结算页是值守记录。

设计优先级依次为：

1. 一眼建立末日温室世界观。
2. 一秒找到当前最重要的操作。
3. 清楚理解生命、光能、进度和危险状态。
4. 以 AI 生成图像提供空间、材质和叙事，以 Godot 控件提供文字、数值和交互。

本规范不改变固定七夜玩法、本地存档契约或 `start_requested` 主流程。

## 2. 视觉系统

采用三层结构：

- **底层材质**：深夜蓝黑纸张、温室玻璃、氧化黄铜、旧木、深棕紫阴影和金色生命光脉。
- **通用组件**：按钮、面板、标签、卡片、进度条、页签、弹窗、提示和焦点状态共用尺寸与交互规则。
- **页面皮肤**：主菜单/图鉴偏记录册，战斗偏园艺仪器，结算和重大选择偏仪式档案。

材质只负责氛围和层次，不得降低文字、敌人、母花、光脉或主要操作的可读性。

## 3. AI 生成素材规范

当前生成素材：

- `art_source/main_menu_background.generated.png`：废弃温室背景，太阳母花位于偏左中心，右侧约 36% 为低细节菜单安全区。
- `art_source/ui_sheet.png`：面板、按钮四态、图标和进度条材质表。
- 对应提示词和报告保存在 `art_source/prompts/` 与 `art_source/*.report.json`。

使用原则：

- AI 负责背景、材质、插图、图标和氛围。
- Godot 负责文字、数字、动态进度、输入焦点、页签、滚动、弹窗和本地化。
- AI 素材不能直接作为交互组件整体拉伸。
- 面板和按钮必须裁切为九宫格或等价可伸缩资源；图标、卡牌和进度条必须独立裁切。
- AI 不生成最终文字、数字、快捷键、数值或完整交互界面。

每张新图必须检查：无错误文字/水印；主体完整；光源方向一致；UI 安全区足够安静；缩小后轮廓仍可识别；透明边缘无黑边/白边；进入 Godot 后文字和控件仍清晰。

### AI 提示词固定结构

每次生成必须明确：用途、主体、构图、安全区、画风、光照、色板、禁止项和避免项。背景提示词必须包含 `exact 16:9`、`no words`、`no UI`、`no watermark` 和明确的菜单安全区；UI 材质提示词必须要求正视角、等尺寸、空白文字区、可九宫格裁切。

### 尺寸

```text
spacing: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px
control: 32 / 36 / 44 / 56 / 64 / 72 px
icon: 16 / 24 / 32 / 48 / 72 / 96 px
border: 1 / 2 / 3 px

```

安全区：左右 48 px、上下 28 px；战斗 HUD 内部最小边距 22 px。重要信息不得贴边。

### 字体

标题使用具有适度书卷感且清晰的中文字体；界面使用清晰的中文无衬线字体。字号等级：12、14、16、20、22、26、32、46 px。正文不用纯白；金色只用于标题、关键数值、当前焦点和主要操作。

### 动效

页面进入 0.24–0.34 秒，按钮反馈 0.08–0.16 秒，标准切换 0.18–0.24 秒。页面位移 12–24 px，按钮悬停最多 2%。减少动态效果时关闭持续呼吸和大幅位移，只保留短淡入淡出、焦点和数值变化。

## 5. 通用组件

### 按钮

- 一级按钮：高 56 px，最小宽 200 px，每页通常只有一个。
- 二级按钮：高 44 px，最小宽 144 px。
- 文字按钮：高 36 px，无完整背景，用于退出、关闭和低优先级操作。
- 危险按钮使用暗红棕，不使用纯红，不比一级按钮更醒目。
- 必须实现 Normal、Hover、Pressed、Focus、Selected、Disabled、Loading 状态。
- Focus 不能只靠颜色，必须有内描边或植物形标记。

### 面板

- 页面主面板：透明度约 92%，内边距 32 px，1–2 px 细边框。
- 浮层面板：透明度约 96%，内边距 24 px，打开时背景加 55%–68% 遮罩。
- HUD 面板：透明度 75%–88%，边框不超过 2 px，不使用大型角花。
- 卡片：统一高度和外接框，插图约占 45%–55%，信息顺序固定。

### 状态与提示

状态不能只靠颜色表达，必须同时有图标、轮廓或文字。临时战斗提示位于中央上方，普通提示最多 2.5 秒；世界空间数字靠近对象，不能遮挡轮廓。弹窗必须限制焦点，`Esc` 关闭当前层而不是穿透退出。

## 6. 页面布局

### 主菜单

左侧 64%–68% 为温室叙事空间，右侧 32%–36% 为操作区。标题和副文案位于左上或母花上方，右上为小型账号铭牌，右侧窄长面板按“继续守夜、配置卡组、七夜记录、温室图鉴、设置、退出游戏”排列。主按钮直接显示当前夜晚摘要。背景母花不得被长期遮挡，菜单面板透明度约 78%–86%。

### 账号管理

从右侧打开档案抽屉，不离开主菜单背景。当前账号置顶，其他账号列表滚动，创建账号在抽屉内展开；删除必须二次确认并明确说明不可恢复。

### 七夜记录

使用一条横向七节点根脉展示进度。已完成金色，当前暖白光环，未解锁灰紫，首领夜使用特殊轮廓。右侧显示夜间插图、天气、威胁、最高波次和当前状态。固定七夜，不提供跳关。

### 卡组配置

左侧 62%–68% 为卡牌库，右侧为当前卡组，底部为详情栏。卡牌库使用 3–4 列网格；当前卡组使用紧凑列表。点击加入，点击项目或减号移除；未满足限制时保存按钮禁用并显示原因。稀有度使用边框层级、叶片角标和太阳印章，不依赖大面积色块。

### 温室图鉴

使用“左侧条目列表 + 右侧标本详情”。固定顺序为名称、类型、插图、功能摘要、详细记录、发现状态。未解锁条目保留模糊轮廓和发现线索，不使用纯黑锁屏。

### 设置

按音频、显示、操作、辅助功能分组。标签左对齐，控件右对齐，滑块/开关/下拉菜单使用原生控件。预留 UI 缩放、减少动态、屏幕震动、高对比状态图标等扩展位。

## 7. 战斗 HUD

顶部拆为三个独立模块：左侧母花生命，中间夜晚/波次，右侧光能。中央约 70% 保持开放。底部为行动卡匣，右侧独立主动技能，边缘显示雷达和屏幕外高威胁方向。

母花生命模块宽 280–320 px；光能模块宽 230–270 px；行动栏高 76–96 px；卡牌显示快捷键、费用、图标、名称和一句功能摘要；完整说明在悬停或聚焦提示中显示。雷达只显示母花、主要光脉节点、敌人方向、首领和断裂节点。

白昼阶段显示“开始守夜”一级按钮；夜战阶段显示波次和行动；暂停菜单只保留继续、设置、操作和返回主界面。战斗 HUD 不使用整屏大面板，不遮挡母花、敌人和光脉。

## 8. 选择与结算

母花进化使用居中的三选一仪式面板，每张选择卡包含 AI 插图、名称、核心效果和代价；背景降低亮度但保留母花上下文，选择后再确认。

胜利结算依次展示结果、夜晚、母花状态、光脉存活、战斗成绩、奖励和下一步；失败结算说明主要失守原因，并提供“调整卡组”和“重新守夜”。失败不使用满屏红色或惩罚性震屏。

## 9. Godot 落地边界

建议逐步建立：

```text
ui/theme/game_theme.tres
ui/theme/ui_tokens.gd
ui/components/
ui/screens/
ui/hud/
```

`game_theme.tres` 负责字体和通用控件样式；`ui_tokens.gd` 负责间距、安全区、动效和特殊状态；场景文件负责节点、容器、锚点和素材；脚本负责数据绑定、状态、交互、焦点和动画触发。

当前 `scripts/main_menu.gd` 与 `scripts/hud.gd` 中的重复颜色、字号和 StyleBox 应逐步迁移到 Theme/Token。页面布局优先使用 `MarginContainer`、`VBoxContainer`、`HBoxContainer`、`GridContainer`、锚点和最小尺寸，绝对坐标只用于受控装饰。

AI UI Sheet 应裁切为 `NinePatchRect` 或等价 `StyleBoxTexture`；动态文字、数值、ProgressBar 填充、焦点和本地化必须由 Godot 绘制。

## 11. 验收标准

### 功能

- 所有页面入口、返回、`Esc`、键盘焦点和滚动行为一致。
- 弹窗不穿透点击，禁用控件不获得焦点。
- 减少动态效果能关闭持续动画。
- 存档、设置、卡组和页面状态正确显示。

### 视觉

- 1152×648、1280×720、1920×1080、2560×1440 及至少一种 16:10 分辨率无裁切。
- 九宫格边框不变形，文字不遮挡插图和战场主体。
- AI 素材无错误文字、水印、黑边、白边和风格漂移。
- 五秒内能找到主操作，一秒内能识别当前焦点。
- 正常、危险、禁用状态不只靠颜色区分。
- 页面仍然属于“末日温室园艺档案”，装饰不能抢过功能信息。

## 12. 实施顺序

1. 建立 Token、字体和统一 Theme。
2. 处理 AI UI Sheet，生成九宫格面板、按钮状态、图标和进度条。
3. 重构主菜单和页面顶栏。
4. 建立通用按钮、面板、弹窗、提示和卡片组件。
5. 重构战斗顶部状态、行动栏、雷达和主动技能。
6. 完成进化选择与胜负结算。
7. 完成七夜记录、卡组、图鉴和设置。
8. 补充第二批 AI 插图和辅助功能。
9. 做多分辨率、输入焦点和视觉验收。

本规范只记录设计与实现边界，不执行 Git 操作，也不要求在本阶段立即改动现有脚本。
