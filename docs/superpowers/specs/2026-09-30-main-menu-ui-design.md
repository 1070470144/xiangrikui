# 主界面 UI 视觉升级设计

## 目标

为《最后的向日葵》主界面生成并接入一张统一的“夜间花园”大背景，同时保留现有菜单功能、节点命名与键盘焦点行为。

## 视觉方向

- 16:9 夜间温室背景：深蓝绿底、荧光植物轮廓、左侧标题留白、右侧菜单区域压暗。
- 菜单按钮不使用生成图片，全部由 Godot `StyleBoxFlat` 绘制，避免继续依赖旧素材。

## 接入边界

- 新背景替换 `assets/backgrounds/ART_BG_MainMenu_Greenhouse.png`，继续由 `ArtLibrary` 暴露路径。
- `scripts/main_menu.gd` 继续负责布局、动画和交互；主界面按钮使用代码样式。
- 删除主界面专用的旧按钮图片、原始图和生成报告。
- 保留现有 `MainMenuBackground`、`MenuJournal`、`PrimaryStartButton` 等节点名，确保测试与自动化捕获脚本不受影响。

## 验证

- 运行现有主菜单 UI 测试与截图捕获脚本。
- 验证主按钮可获得焦点、开始/卡组/记录/图鉴/设置入口仍可用。
- 验证素材缺失时仍有颜色样式回退，不阻断启动。
