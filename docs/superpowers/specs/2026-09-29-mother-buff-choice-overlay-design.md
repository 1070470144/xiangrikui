# 母花 Buff 三选一全屏界面设计

## 目标

修复白昼母花强化区域只显示标题、不显示选项的问题，并将母花 Buff 三选一改为独立的全屏模态选择界面。

## 界面结构

- 在战斗 HUD 最上层增加覆盖整个视口的选择层。
- 选择层背景使用半透明深色遮罩，保留战场轮廓但明显降低背景亮度。
- 标题“选择今日的母花强化”位于屏幕中央区域上方。
- 三个候选 Buff 使用尺寸完全一致的卡牌，横向居中排列。
- 每张卡牌至少显示强化名称和核心效果说明，整张卡均可点击。
- 选择层拦截鼠标输入，显示期间不能操作战场或底部 HUD。

## 显示与交互

- 仅当 `mother_choice_pending` 为真且候选列表非空时显示选择层。
- 候选内容变化时重新生成三张卡牌；相同候选重复刷新时不重复创建控件。
- 点击任意卡牌后沿用现有 `mother_card_requested` 信号和游戏规则进行选择。
- 选择成功后立即隐藏完整选择层，包括遮罩、标题和全部卡牌，恢复正常主界面。
- 候选为空时隐藏完整选择层，禁止显示只有标题的空面板。

## 数据与资源

- 方向卡从 `ContentData.get_mother_path()` 读取，后续强化卡从 `ContentData.get_mother_upgrade()` 读取。
- 名称和效果说明由 Godot 字体系统绘制，不烘焙进图片。
- 继续使用现有 HUD 装饰资源与 `battle_hud` art manifest；若现有卡牌底图不足，则先使用可读的程序化卡牌样式，并同步补充 manifest 绑定记录，不在本次未经确认时调用图片生成模型。

## 验收标准

1. 首日和后续白昼均显示三个可读、可点击且等尺寸的强化卡牌。
2. 三选一界面覆盖全屏，背景半透明变暗，底层控件无法误触。
3. 选择一张卡后全屏界面立即消失，强化正常生效。
4. 空候选状态不会留下空白中央面板。
5. 现有母花进化、白昼/夜晚切换和 HUD 测试继续通过，并新增上述显示行为的自动化覆盖。
