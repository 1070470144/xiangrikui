# 右侧卡组布局与旋转卡牌 · 2026-09-30

删除右上详情面板及其刷新逻辑，右侧保留当前卡组清单、光能分布和校验反馈。1152×648 下卡组清单可直接显示六种初始卡，不再与详情争用空间；双向拖拽保留。

点击展示改为 350×430 的竖向双面卡牌。正面有插画、名称、光能消耗、品质、时段和目标；背面提供完整自然语言效果、数值、携带限制与解锁费用。背面描述区可滚动。卡牌外部只保留旋转、加入/解锁与关闭按钮。

`scripts/card_turntable.gd` 使用连续角度和余弦宽度模拟绕竖轴旋转，半圈切换正反面，边缘状态降低亮度。点击或旋转按钮播放翻面动画；按住左右拖动自由旋转，上下轻微倾斜，松手吸附到正面或背面。重复打开重置旋转；不改变卡组规则或消耗。

卡组测试通过，包括 Godot 图形运行中实际鼠标点击翻面、拖动到侧边、松手停在背面、再次打开替换卡牌，以及原有双向组牌拖拽。运行截图：`tmp/deck-turntable-overview.png`、`tmp/deck-turntable-front.png`、`tmp/deck-turntable-back.png`。
