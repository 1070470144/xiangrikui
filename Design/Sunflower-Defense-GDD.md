# 《最后的向日葵》游戏设计文档

> 文档版本：0.1 原型方案  
> 更新时间：2026-09-24  
> 类型：单人 2D 黑暗奇幻花园防守 Roguelite  
> 目标平台：Windows / Steam  
> 开发引擎：Unity / Tuanjie 2022.3

## 1. 一句话概念

玩家扮演末代园丁，在太阳熄灭后的世界里守护保存最后太阳碎片的太阳母花。白天从母花向外铺设光脉并布置植物防线，夜晚阴影生物从环形花园四周袭来，植物自动战斗，玩家通过击杀敌人获得光能并释放阳光技能，努力撑到黎明。

## 2. 核心体验与设计支柱

核心体验是**紧张与守护**：防线可能从任意方向崩溃，但玩家始终保留一次关键救场机会。

1. **光是空间，也是生命线**：植物需要光脉支持；光脉断裂会让外围防线失效。
2. **威胁来自四面八方**：中央核心和环形战场制造包围感。
3. **自动战斗，主动救场**：植物持续输出，玩家负责观察敌情和把握技能时机。
4. **撤退保存希望**：每个白天都可以安全撤退并带走本局可提取种子；战败只能带走 10%，种子用于解锁战斗卡和有上限的母花基础成长。

## 3. 世界与叙事

太阳已经熄灭。太阳母花保存着最后一块太阳碎片，是世界仅存的稳定光源。黑暗中诞生的阴影生物会被光吸引，并试图吞噬母花。

主角是沉默的末代园丁。故事主要通过废弃温室、断裂的园艺工具、旧花牌、植物从金黄变为灰黑的视觉变化，以及阴影生物的区域变异表达，不依赖大量对白。

## 4. 核心玩法循环

```text
进入花园区域
  → 白天限时布置光脉与植物
  → 黑夜降临，阴影生物从四周进攻
  → 植物自动攻击，玩家观察缺口
  → 击杀敌人获得光能，释放阳光技能救场
  → 撑过波次并选择局内强化
  → 进入下一区域，最终挑战太阳吞噬者
```

## 5. 战场结构

- 战场为单个环形花园。
- 太阳母花位于中央，是唯一核心目标。
- 敌人从四周黑暗区域生成并向母花推进。
- 母花向外连接光脉植物，形成可扩展的光照网络。
- 植物只有处于有效光区时才能发挥完整能力。
- 光脉节点被摧毁后，后方区域断光，植物受到削弱或停止工作。

正式游戏使用随机区域；第一版原型固定一个区域，验证四面受敌、环形布局、光脉断裂和主动技能是否有趣。

## 6. 昼夜与资源

### 白天

限时准备；玩家铺设或修复光脉、种植或移动植物；白天结束后自动进入夜晚。

### 夜晚

敌人按波次从四周生成；植物自动寻找目标并战斗；玩家主要通过阳光技能干预战局。

### 光能

- 主要来源：击杀阴影生物。
- 保底来源：太阳母花缓慢恢复少量光能。
- 用途：释放阳光技能。
- 目的：让防守成功带来正反馈，并给劣势局留下翻盘机会。

## 7. 植物与技能方向

| 植物 | 职责 | 设计重点 |
|---|---|---|
| 光脉芽 | 连接母花与外围区域 | 是光网络基础节点，不只是炮塔 |
| 荆棘花 | 近距离持续伤害 | 保护关键光脉节点 |
| 棱镜花 | 远距离或分裂攻击 | 鼓励延伸光脉 |
| 守灯花 | 局部光照或减缓断光 | 防止单点破坏导致全线崩溃 |

| 技能 | 作用 |
|---|---|
| 太阳爆闪 | 目标区域范围伤害并短暂驱散黑暗 |
| 光之修复 | 修复母花或关键光脉节点 |
| 黎明脉冲 | 短时间扩大有效光区 |

## 8. 敌人方向

| 敌人 | 行为 | 迫使玩家关注 |
|---|---|---|
| 影兽 | 速度中等，直接攻击母花 | 基础防线完整性 |
| 蚀芽虫 | 优先攻击光脉节点 | 光网络保护 |
| 黑潮巨影 | 生命高、速度慢、压迫前线 | 技能时机和集火 |

## 9. 当前关卡结构与远期 Roguelite 规划

当前原型只包含一个固定环形战场和七夜单关卡战役：前五夜逐步引入八方来敌、酸雨、雷雨和根冠巨像；第六夜是无战斗的补给与防线重构阶段；第七夜击败“太阳吞噬者”后通关。当前版本不提供无限模式和难度选择，具体数值以 `Design/Sunflower-Defense-Balance.md` 为准。

完整游戏的远期规划是一局包含 5 个随机区域，最后挑战“太阳吞噬者”。区域结束后提供新植物、新技能、光脉规则变化、临时强化或有风险的强力祝福。该规划不影响当前七夜原型的关卡和数值实现。

七夜扩展版加入两层卡牌和撤退循环：每个白天三选一的母花进化只强化母花；玩家局外构筑十二张整局消耗型战斗卡，用来改变战场。安全撤退和通关带走 100% 可提取种子，战败带走 10%。局外种子用于解锁战斗卡和提升有五级上限的母花基础属性。完整数据以 `Design/Sunflower-Defense-Content-Data.md` 为准。

## 10. 七夜原型范围 Prototype v0.1

### 必须实现

- 单个固定环形战场；
- 中央太阳母花；
- 有限数量的植物或光脉节点；
- 七夜固定流程，第六夜补给，第七夜最终 Boss；
- 多波敌人从八个方向分批生成；
- 敌人移动并攻击母花或光脉；
- 植物自动攻击；
- 击杀增加光能；
- 至少一个阳光主动技能；
- 波次计数和母花生命值；
- 母花被摧毁后显示失败并可重新开始；
- 支持鼠标操作和键盘快捷键。

### 暂不实现

随机区域、5 区域完整战役、无限模式、难度选择、局外解锁界面、Steam 成就与云存档、配音、完整叙事和复杂植物组合系统。

## 11. 原型成功标准

第一次试玩重点验证：

1. 玩家能否在 30 秒内理解“守护中央母花”。
2. 玩家能否看懂光脉网络和断光后果。
3. 四面来敌是否紧张但不混乱。
4. 玩家是否会主动等待合适时机释放阳光技能。
5. 击杀获得光能是否形成“越守越有机会”的反馈。
6. 失败是否来自可理解的决策，而不是随机偷袭。
7. 玩家是否愿意再开一局尝试不同布阵。

如果第 3、4、7 项同时失败，应优先调整战场规模、敌人可读性和技能反馈，而不是继续添加植物或敌人。

## 12. 主要风险与对策

- **四面受敌导致信息过载**：使用方向警告、颜色和音效；限制同时活跃的敌人种类。
- **自动战斗让玩家缺少参与感**：把关键决策放在光脉布局、资源积攒和技能时机。
- **光脉断裂造成失败滚雪球**：保留母花少量光能恢复，提供光之修复，断光先削弱后腐化。
- **主题像普通塔防换皮**：坚持“光脉网络”和“环形包围”这两个不可替代的核心规则。
