# 《最后的向日葵》美术风格规范

> 文档版本：1.0
> 建立日期：2026-09-24
> 项目类型：Unity 2D 黑暗奇幻花园防守 Roguelite
> 目标平台：Windows / Steam
> 适用范围：场景、植物、敌人、特效、UI、动画、资源导入与美术验收

## 1. 美术方向结论

项目正式采用：

> **末日温室绘本风**
>
> 真实植物学结构 + 厚涂绘本质感 + 金色生命光脉 + 蓝紫腐化阴影。

美术必须同时传达两种情绪：

- 世界已经衰败、寒冷、危险；
- 太阳母花仍然温暖、明亮，并值得玩家守护。

本项目不采用像素画、纯扁平卡通、纯写实摄影风或高饱和糖果色风格。

## 2. 已确定的视觉决策

| 项目 | 决策 |
|---|---|
| 资源类型 | 高清手绘 2D |
| 视角 | 3/4 斜俯视 |
| 摄像机 | Unity 2D 正交相机 |
| 材质 | 厚涂绘本、可见笔触、轻微纸张纹理 |
| 植物 | 参考真实植物结构，进行战斗功能夸张 |
| 敌人 | 怪兽化、昆虫化，结构清晰、行为可读 |
| 氛围 | 暗黑但温暖 |
| 核心对比 | 冷色腐化环境 vs 暖色太阳生命光 |
| 画面重点 | 中央太阳母花、光脉网络、敌人入侵方向 |
| 光照表现 | 2D Light、手绘发光层、粒子三者结合 |

## 3. 视觉叙事原则

### 3.1 光是生命

光不是普通装饰，而是游戏规则的视觉化表现。光脉应当让玩家一眼看出：

- 哪些区域仍然有效；
- 哪些植物正在获得支持；
- 哪些光脉节点即将失效；
- 哪些区域已经被黑暗吞噬。

光脉从太阳母花向外扩散，颜色和亮度随网络状态变化：

| 状态 | 视觉表现 |
|---|---|
| 正常 | 金黄色主光，暖白高光，缓慢流动的光粒子 |
| 受损 | 黄色变暗，边缘出现断续闪烁，粒子减少 |
| 断裂 | 光脉变为灰褐色或冷紫色，出现碎裂和烟尘 |
| 修复中 | 由节点向外产生连续金色脉冲 |
| 技能强化 | 暖白核心、金橙外圈、明显扩散波纹 |

### 3.2 黑暗是吞噬

黑暗不能只表现为透明黑色覆盖层。它应具有生物感和侵蚀感：

- 边缘像烟雾、菌丝、根须或液体阴影；
- 吞噬区域出现冷青、暗紫和少量暗红；
- 黑暗靠近母花时，画面边缘和植物颜色逐步失去饱和度；
- 敌人的轮廓必须比环境更清楚，不能融入背景。

### 3.3 中央核心是视觉锚点

太阳母花是整场战斗的视觉中心。它必须满足：

- 轮廓比普通植物更复杂；
- 亮度和暖色强度最高；
- 生命状态有明显阶段变化；
- 即使缩小到游戏画面的一半，也能看出它是核心目标；
- 任何 UI、特效或敌人都不能长期遮挡其主体轮廓。

## 4. 色彩系统

### 4.1 基础色板

颜色不是硬性限制，但所有新资源应尽量接近以下色彩关系。

| 用途 | 色彩方向 | 参考色 |
|---|---|---|
| 深夜背景 | 深蓝黑 | `#111827` |
| 远景阴影 | 灰紫 | `#25263A` |
| 土壤与石材 | 暗棕紫 | `#3A3032` |
| 普通叶片 | 墨绿 | `#263D35` |
| 枯萎植物 | 灰绿、枯黄 | `#69705A` / `#A08A4A` |
| 生命光脉 | 金黄 | `#E5B94B` |
| 光脉高光 | 暖白 | `#FFF0B0` |
| 技能光焰 | 金橙 | `#F59E45` |
| 敌人主体 | 黑紫 | `#211C32` |
| 敌人冷光 | 冷青 | `#4C8490` |
| 腐化警告 | 暗红 | `#8E3D4A` |

### 4.2 色彩使用规则

- 环境以冷色、低饱和为主。
- 植物默认比环境更暖、更有色彩层次。
- 光脉和阳光技能使用金黄、暖橙、暖白。
- 敌人使用黑紫和冷青，避免与光脉使用相同的高亮黄色。
- 暗红只用于高危险状态、首领、重伤或腐化警告。
- 不使用纯黑作为大面积填充，不使用纯白作为普通高光。
- 同一画面中最亮的区域必须优先属于母花、光脉或主动技能。

## 5. 造型语言

### 5.1 植物

植物以真实植物为基础，但需要服务玩法识别：

- 叶片、花瓣、花蕊和根茎要有可信的生长方向；
- 攻击方式通过花朵开合、根须伸展、叶片转向或光线聚焦表达；
- 功能不同的植物必须有不同的主体轮廓，而不只是换颜色；
- 植物底部要有稳定的接地形状，避免像漂浮图标；
- 受断光影响时，优先改变姿态、饱和度和局部亮度，不直接隐藏整个植物。

首批植物的造型重点：

| 植物 | 造型方向 |
|---|---|
| 光脉芽 | 根茎连接地面，中心有细小金色光核 |
| 荆棘花 | 低矮、横向扩张、尖刺和卷曲藤蔓明显 |
| 棱镜花 | 花瓣呈晶体或棱镜切面，攻击时分裂出彩色光束 |
| 守灯花 | 花朵像小型灯盏，主体有持续发光的花心 |
| 太阳母花 | 多层花瓣、巨大花心、根系与光脉相连，视觉等级最高 |

### 5.2 敌人

敌人不是普通动物换颜色，而是被黑暗侵蚀后的生物。

- 身体结构要能体现速度、攻击目标和威胁等级；
- 轮廓优先于内部细节；
- 运动方向要通过肢体、触须、背刺或拖尾明确表达；
- 影兽强调扑袭和压迫感；
- 蚀芽虫强调啃咬、钻入和破坏节点；
- 黑潮巨影强调体积、缓慢移动和遮蔽感；
- 敌人受光、受击和死亡时必须有明确的亮度变化。

### 5.3 轮廓与细节

- 不使用纯黑描边；优先使用深蓝紫或深棕紫。
- 普通单位采用清晰外轮廓和有限内部细节。
- 重要单位可以增加花瓣层、根须层、晶体层或腐化纹理。
- 背景细节不得与可交互植物和敌人竞争。
- 细节密度从中心向外围逐步降低，外围区域允许使用更抽象的笔触和纹理。

## 6. 场景风格

### 6.1 环形花园构成

场景采用接近正圆的环形花园布局，但用 3/4 斜俯视表现纵深：

1. 中央：太阳母花与核心根系；
2. 内圈：主要光脉和关键防守植物；
3. 中圈：可布置植物、节点和战斗空间；
4. 外圈：黑暗生成区、废弃温室边缘、破碎围栏和杂草；
5. 画面边缘：低清晰度的黑暗和雾气，作为威胁来源。

### 6.2 场景材质

- 土壤：厚涂块面、湿润暗色、少量根须和石块。
- 石材：粗糙、破裂、不规则，颜色偏棕紫。
- 温室遗迹：锈蚀金属、碎玻璃、木制园艺结构。
- 植物残骸：干枯叶片、断茎、菌丝和黑色藤蔓。
- 玻璃与水滴：只在关键场景中使用，避免造成视觉噪声。

### 6.3 层次控制

| 层级 | 内容 | 表现要求 |
|---|---|---|
| 前景 | 少量枝叶、雾、暗色框景 | 半透明、低对比，不遮挡战斗 |
| 战斗层 | 植物、敌人、光脉、弹道 | 对比最高，轮廓清晰 |
| 中景 | 土地、道路、花坛、残骸 | 服务空间识别，不抢主体 |
| 背景 | 温室、围栏、树林、黑暗 | 低饱和、低细节、稳定构图 |
| 特效层 | 光晕、受击、技能、粒子 | 使用短时高亮，避免常驻过曝 |

## 7. 光照与特效规范

### 7.1 光照原则

Unity 2D 中使用正交相机和 2D 光照时，手绘资源仍应保留基础明暗，不依赖实时光照单独完成造型。建议采用：

- 手绘底色和基础阴影：负责稳定造型；
- Unity 2D Light：负责区域状态和动态氛围；
- 发光叠加层：负责光脉、技能和受击反馈；
- 粒子系统：负责流动、扩散、修复和死亡反馈。

不要让实时光照把植物主体照成完全平坦的纯色，也不要让 Bloom 长时间覆盖单位轮廓。

### 7.2 特效优先级

1. 阳光技能：最高亮度、最大范围、最强反馈；
2. 太阳母花和光脉：持续可见的生命状态；
3. 植物攻击：清晰表达方向和命中；
4. 敌人受击：短促、偏冷或偏暖的闪烁；
5. 环境粒子：低对比、低密度，只增强氛围。

### 7.3 特效颜色

- 修复、治疗、护盾：暖白 + 金黄。
- 攻击、爆闪、范围技能：金橙 + 暖白。
- 腐化、断光、危险：冷紫 + 暗红。
- 敌人受击：冷白或偏青白短闪。
- 禁止所有特效同时使用高饱和颜色。

## 8. UI 风格

UI 采用“旧园艺记录册 + 发光仪器”的方向：

- 面板：深蓝灰或深棕紫半透明底；
- 边框：细金线、磨损纸边或暗色金属边；
- 选中状态：金色光线、轻微呼吸亮度；
- 警告状态：暗红，不使用大面积纯红；
- 图标：植物学剪影、种子、花瓣、根脉和太阳符号；
- 字体：优先选择清晰易读的中文无衬线字体，标题可使用少量手写或古典衬线风格；
- 数值与状态必须优先保证识别，不为装饰牺牲可读性。

UI 不应采用现代科技 HUD、霓虹赛博风或过度玻璃拟态。

## 9. 动画规范

### 9.1 植物动画

植物动画以“生长、呼吸、蓄力、释放、受损”为主：

- 待机：轻微摆动或光脉呼吸，循环不能过大；
- 蓄力：花瓣收拢、光线聚集、颜色变暖；
- 攻击：动作短、方向明确、命中瞬间有高亮；
- 受损：姿态下垂、局部变暗、光脉闪烁；
- 断光：降低动作频率和亮度，但保留轮廓；
- 修复：从根部或节点向上恢复颜色和亮度。

### 9.2 敌人动画

- 影兽：低重心、连续扑袭、移动拖影有限；
- 蚀芽虫：快速爬行、停顿啃咬、节点破坏动作明确；
- 黑潮巨影：慢速、重心压迫、受击反馈沉重；
- 死亡：被光驱散、碎裂、枯萎或化为烟尘，不使用过于血腥的表现。

### 9.3 节奏要求

- 战斗动作必须先读轮廓，再读特效。
- 攻击前应有至少一个短暂预备动作。
- 大范围技能必须有施放前提示，避免玩家只看到结果。
- 同一屏幕上的高亮动画数量要受控，防止信息过载。

## 10. Unity 2D 资源技术规范

### 10.1 推荐项目设置

- 使用 Orthographic Camera。
- 默认目标画面为 16:9，项目当前默认分辨率为 1920×1080。
- 高清手绘模式不启用 Pixel Perfect Camera。
- 纹理默认使用 `Sprite (2D and UI)`。
- Filter Mode 使用 `Bilinear` 或项目统一的高质量过滤方案，不使用像素画的 Point 过滤。
- Mipmap 关闭，除非特定大型背景资源明确需要。
- 压缩设置以平台质量为准，关键 UI、光效和透明资源优先使用无损或高质量压缩。
- 透明资源检查边缘色，避免黑边、白边和预乘 Alpha 问题。

### 10.2 推荐排序层

建议建立以下 Sorting Layer：

1. `Background`
2. `Environment`
3. `LightNetwork`
4. `Plants`
5. `Enemies`
6. `Projectiles`
7. `EffectsBehind`
8. `EffectsFront`
9. `Foreground`
10. `UI`

同一角色或植物包含多个 Sprite 时，使用 `Sorting Group` 保持内部排序稳定。

### 10.3 资源尺寸原则

不强制所有资源使用统一像素尺寸，但必须统一视觉比例：

- 太阳母花：屏幕中央最主要的主体，建议占战斗区域直径的约 12%—18%；
- 普通植物：母花主体高度的约 25%—45%；
- 普通敌人：普通植物主体高度的约 35%—70%；
- 黑潮巨影：普通敌人高度的约 150%—220%；
- UI 图标：保持统一外接框、留白和视觉重量；
- 同类资源的底部接地点和透视关系必须一致。

实际尺寸以首张战斗场景灰盒截图校准，不先盲目批量制作。

## 11. 文件夹与命名建议

建议在 `Assets` 下建立：

```text
Assets/
├── Art/
│   ├── Characters/
│   ├── Plants/
│   ├── Enemies/
│   ├── Environment/
│   ├── Effects/
│   ├── UI/
│   ├── Backgrounds/
│   └── Materials/
├── Animations/
├── Prefabs/
│   ├── Plants/
│   ├── Enemies/
│   ├── Effects/
│   └── UI/
├── Scenes/
├── ScriptableObjects/
└── Audio/
```

命名建议：

- 贴图：`ART_<类别>_<名称>_<状态>`
- 动画：`ANIM_<对象>_<动作>`
- 预制体：`PF_<类别>_<名称>`
- 材质：`MAT_<用途>_<名称>`
- 特效：`VFX_<对象>_<效果>`
- UI：`UI_<页面或模块>_<名称>`

示例：

```text
ART_PLANT_ThornFlower_Idle
ART_ENEMY_ShadowBeast_Move
ART_VFX_SunBurst_Main
ANIM_PLANT_PrismFlower_Attack
PF_ENEMY_ErosionBug
MAT_VFX_GoldenPulse
```

## 12. 资源制作优先级

### 第一阶段：验证核心可读性

1. 太阳母花完整立绘与受损版本；
2. 环形花园基础地面；
3. 光脉芽与光脉连接效果；
4. 荆棘花；
5. 影兽；
6. 蚀芽虫；
7. 太阳爆闪；
8. 母花生命、光能和波次 UI。

### 第二阶段：验证策略差异

1. 棱镜花；
2. 守灯花；
3. 黑潮巨影；
4. 光之修复；
5. 黎明脉冲；
6. 断光、修复、腐化的完整状态组。

### 第三阶段：建立正式内容品质

1. 温室遗迹和区域背景；
2. 变异植物和区域主题；
3. 首领太阳吞噬者；
4. Roguelite 祝福图标；
5. 完整 UI 皮肤；
6. 场景转场与叙事插图。

## 13. 美术验收标准

每个资源进入正式场景前，必须检查：

- 缩小到实际游戏尺寸后仍能一眼辨认；
- 轮廓与功能一致，不依赖文字说明；
- 与背景、植物、敌人的明度关系正确；
- 没有纯黑大色块、脏边、白边或透明边缘污染；
- 3/4 视角的受光方向和接地关系一致；
- 动画循环没有明显跳帧、漂移或突然变大变小；
- 特效不遮挡攻击来源、目标和核心生命状态；
- 资源使用统一的色彩、笔触和细节密度；
- 断光、受击、死亡、修复等状态能被玩家快速区分。

## 14. 暂不采用的方向

为保持项目统一，当前阶段暂不采用：

- 像素画和复古低分辨率渲染；
- 纯卡通大头或可爱萌系造型；
- 赛博朋克、霓虹科技 UI；
- 大面积高饱和彩虹色；
- 纯黑剪影导致的敌人不可读；
- 全部资源使用同一种发光效果；
- 依赖实时光照而没有手绘基础明暗的资源；
- 过度复杂、无法在战斗尺寸下识别的背景细节。

## 15. 一句话给美术团队

> 请把《最后的向日葵》画成一座正在被蓝紫黑暗吞噬、却仍由金色生命光脉支撑的末日温室；植物要像真实生命，敌人要像被腐化的生物，所有最暖、最亮的东西都必须服务于“守护最后太阳”的目标。
